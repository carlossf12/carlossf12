## 🚀 Featured Projects

### 🔍 aur-audit

A read-only security auditing CLI for Arch Linux AUR packages, focused on
package inspection, approved baselines, change detection, integrity
verification and auditable history.

**Tech Stack:** Go · Arch Linux · Ed25519 · SHA-256

### [🔒 lock-screen](https://github.com/carlossf12/lock-screen)

A custom lock screen plugin for Omarchy built with Quickshell, preserving
secure session locking and PAM authentication while providing a customized
interface.

**Tech Stack:** QML · Quickshell · Hyprland · Linux
